# 🎵 JioSaavn Streaming Analytics Dashboard | Power BI |SQL Server | AI 

An end-to-end Power BI dashboard analyzing streaming behavior, user demographics, and content performance for a JioSaavn-style music streaming platform, using synthetic/mock data generated via Perplexity.

---

## 📌 Project Overview

This project simulates a music streaming analytics use case, covering how a platform like JioSaavn might track **listening behavior, user engagement, subscription performance, and content trends** across genres, languages, devices, and regions.

The dashboard is built across **3 report pages**:

| Page | Focus |
|---|---|
| **Cover Page** | Branding, artist selection slicer, and app overview |
| **Streaming Overview** | Listening hours trends, total streams, completion & skip rates, state-wise and device-wise streaming |
| **User & Content Insights** | Demographics, genre/language performance, top artists, subscription type mix, and a detailed artist × playlist matrix |

## 🎯 Business Questions Answered

- Which states and devices drive the most streaming activity?
- How does listener engagement (completion vs. skip rate) trend over time?
- Which artists, genres, and languages perform best?
- How do streams break down by subscription type and demographics?
- Which playlists drive the highest streams per artist?

---

## 🛠️ Tools & Techniques Used

- **Power BI Desktop** — data modeling, DAX measures, interactive visuals
- **Perplexity AI** — synthetic dataset generation
  **SQL Server** - generate dataset with run query  
- **DAX** — calculated measures (Completion Rate, Skip Rate, Avg Streams per User, Mobile Share)
- **Power Query** — data cleaning and transformation
- **Slicers & Cross-filtering** — artist, state, and device-level interactivity
